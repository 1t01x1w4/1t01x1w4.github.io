漏洞简述

APP的 VIP/金币付费墙仅由客户端 UI 依据 checkpoint（免费集数）实现；服务端在剧场详情接口中，对超出 checkpoint 的全部付费剧集，向任何普通登录用户原样下发可公开播放的 CDN 直链（son_video_url，无签名、无过期、无用户绑定），攻击者无需支付、无需 root、无需 Hook，即可提取并下载/播放整部付费短剧。

完整过程

测试对象为一个短剧APP，该APP设置有付费剧集，想要观看需要开通VIP会员、充值虚拟币或看广告解锁一定数量剧集。那能否通过hook或者绕过校验的方式获得VIP权限呢？

思路一：客户端 hook

检查 APP 加固情况，发现未加壳，直接提取安装包，用 jadx 进行反编译。

在 com\XXX\XXX\app\util\AESGCMDecryption.java 中可见硬编码密钥及 decrypt 算法，借助AI写出解密脚本。

经过测试，fridahook 可以直接拿到VIP权限即可观看所有付费剧集，但是这种方式需要特定条件：一是一部 root 并安装了 fridaserver 的手机，二是手机必须连接着电脑并运行 fridahook 脚本。虽然我们能够绕过该APP的反调试，但是实际利用条件较为苛刻，难以造成实质性危害。

思路二：服务端对象级授权缺失

  1. 为了直观看清在点击APP的过程中发生了什么，在电脑端用 adb 打开手机端的 fridaserver，另一个终端窗口运行反调试脚本以及明文打印脚本。

  1. 在手机APP上点击首页，成功捕获到首页请求明文，说明脚本工作正常。

  1. 以非 VIP 账号登录并打开任意付费剧集，在运行 frida 脚本的终端中查看 [DEC] 块输出：arg2 为密钥，PLAINTEXT 为解密后的 JSON 数据（其中 theaters[].son_video_url 含付费剧集直链）。

  1. 访问付费直链，修改链接中最后一级 {集数}.mp4 中的集数即可直接观看对应剧集，不论这一集是否需要付费。

  1. 而APP分享短剧时生成的链接（形如https://XXX.com/share-video/index.html?theater_parent_id=2620&app_id=7&channel=wechat）中则出现了对应短剧的 theater_parent_id 值，通过构造https://XXX.com/v1/share/tms/theater_parent?theater_parent_id=2662&app_id=7这样的curl请求即可拿到对应短剧的剧集直链，即可免费观看任意短剧的任意付费剧集。

危害

  1. 付费内容零成本泄露：任意普通登录账号即可从剧场详情接口拿到全部付费剧集的可播放直链，绕过 VIP、金币和广告解锁，直接观看或下载整部短剧，直接蚕食平台的会员与付费收入。
  2. 可脚本化、批量利用：利用过程无需 root、无需 Hook，也不依赖特定客户端版本；攻击者只需维持一个普通账号，遍历 theater_parent_id 即可批量拉取全站短剧的付费资源，成本极低，且平台难以控制影响范围。
  3. 直链不受控，传播难回收：son_video_url 无签名、无过期时间、不绑定用户，一旦泄露即可长期有效并跨用户传播，容易被第三方站点盗链或聚合。平台无法通过封禁单个账号止损，还需承担额外的 CDN 带宽成本。
  4. 版权与商业风险：付费内容被批量抓取后可能流入盗版渠道，影响版权方合作与平台声誉，对以付费分账为主要收入模式的短剧业务影响尤为明显。

修复建议

  1. 服务端补齐剧集级鉴权（根本修复）：剧场详情、选集与分享接口在返回剧集信息前，须按当前登录用户对每一集的 VIP/购买/解锁状态进行校验；超出 checkpoint 的付费集只返回标题、集数等展示信息，不下发可播放地址。客户端付费墙只能用于展示，不能作为权限边界。
  2. 播放地址改为短时效签名 URL：不要直接下发长期有效的 CDN 直链。由服务端签发绑定 user_id、episode_id、过期时间与签名的播放 token 或签名 URL，播放时由 CDN 校验；有效期尽量短，并限制单账号的并发与请求频次。
  3. 分享接口做对象级授权：theater_parent 接口应校验请求者是否有权访问该剧场，或仅返回公开的预览信息；对可枚举 ID 增加归属校验、频率限制和异常遍历风控，避免「分享」接口成为全站数据导出入口。
  4. CDN 侧启用防盗链：为点播地址开启 URL 鉴权或 Token 鉴权，避免直链被第三方长期引用；对已泄露的资源可轮换密钥或下架处理。
  5. 密钥与客户端加固（辅助措施）：修复 AESGCMDecryption 中硬编码密钥的问题，改为按版本/设备动态下发，并配合代码混淆与完整性校验。该措施能提高分析成本，但不能替代服务端鉴权。
  6. 修复验证：用普通非 VIP 账号重放原请求，确认响应中不再包含付费集的 son_video_url；篡改 theater_parent_id 访问未授权剧场时应返回 403 或无数据；已签发的旧直链应在有效期内失效。
